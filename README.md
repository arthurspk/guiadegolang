## :dart: O guia para alavancar a sua carreira

> Go (ou Golang) é a linguagem de código aberto criada pelo Google em 2009 para resolver um problema muito concreto: compilar rápido, rodar rápido e ser simples o bastante para times grandes manterem juntos. Hoje é a linguagem por trás de Docker, Kubernetes, Terraform, Prometheus e boa parte da infraestrutura de nuvem do mundo, além de ser peça central em backends de alta performance no Brasil e fora dele. Este guia reúne documentação oficial, cursos gratuitos e pagos, livros, canais, ferramentas, projetos práticos e um capítulo dedicado a usar IA no dia a dia com Go — tudo verificado e organizado para quem está começando do zero ou já programa em outra linguagem e quer migrar o raciocínio para Go, do primeiro `go run` a goroutines e generics.

## 💡 Nossa proposta

> A proposta deste guia é dar uma ideia sobre o atual panorama e guiá-lo se você estiver confuso sobre qual será o seu próximo aprendizado, sem influenciar você a seguir os 'hypes' e 'trends' do momento. Acreditamos que com um maior conhecimento das diferentes estruturas e soluções disponíveis poderá escolher a ferramenta que melhor se aplica às suas demandas. E lembre-se, 'hypes' e 'trends' nem sempre são as melhores opções.

## 🛠️ Ferramentas

> Ambiente e qualidade de código

- [Go Playground (oficial)](https://go.dev/play/) — Editor online oficial para testar e compartilhar trechos de código Go pelo navegador.
- [GoLand (JetBrains)](https://www.jetbrains.com/go/) — IDE dedicada a Go, com refatoração avançada e debugger integrado. Ferramenta paga (com trial).
- [Go extension for VS Code](https://marketplace.visualstudio.com/items?itemName=golang.go) — Extensão oficial do time do Go para VS Code: autocomplete, debug e formatação.
- [golangci-lint](https://golangci-lint.run/) — Agregador de dezenas de linters para Go em uma única ferramenta rápida, padrão de mercado.
- [staticcheck](https://staticcheck.dev/) — Analisador estático avançado que encontra bugs, código morto e problemas de performance.
- [Delve](https://github.com/go-delve/delve) — Debugger padrão da comunidade Go, usado por IDEs e editores.
- [air](https://github.com/air-verse/air) — Live reload para aplicações Go: recompila e reinicia automaticamente a cada alteração.
- [pprof](https://github.com/google/pprof) — Ferramenta oficial do Google para profiling de CPU e memória de aplicações Go.
- [goreleaser](https://goreleaser.com/) — Automatiza build, empacotamento e publicação de binários Go multiplataforma.

> Frameworks web e APIs

- [Gin](https://gin-gonic.com/) — Framework web mais popular do ecossistema Go, focado em performance e API simples.
- [Echo](https://echo.labstack.com/) — Framework web minimalista de alta performance, com middlewares embutidos.
- [Fiber](https://gofiber.io/) — Framework web inspirado no Express.js, construído sobre o motor HTTP fasthttp.
- [Chi](https://go-chi.io/) — Roteador HTTP leve e 100% compatível com `net/http`, sem dependências externas.
- [gRPC-Go](https://grpc.io/docs/languages/go/) — Implementação oficial em Go do gRPC, framework de comunicação entre serviços do Google.
- [go-swagger](https://github.com/go-swagger/go-swagger) — Gera documentação OpenAPI/Swagger a partir de código Go, ou o inverso.

> Dados, configuração e CLI

- [GORM](https://gorm.io/) — ORM mais usado do ecossistema Go, com suporte a migrações, associações e hooks.
- [sqlc](https://sqlc.dev/) — Gera código Go type-safe a partir de consultas SQL puras, sem ORM.
- [Bun](https://bun.uptrace.dev/) — ORM leve e moderno, com bom suporte a PostgreSQL e migrações.
- [Cobra](https://github.com/spf13/cobra) — Biblioteca padrão de mercado para criar CLIs em Go, usada por `kubectl`, `hugo` e outros.
- [Viper](https://github.com/spf13/viper) — Gerenciamento de configuração em Go: arquivos, variáveis de ambiente e flags em um só lugar.
- [Wire](https://github.com/google/wire) — Ferramenta do Google para injeção de dependência em tempo de compilação.

> Testes, logging e observabilidade

- [testify](https://github.com/stretchr/testify) — Biblioteca de asserções e mocks mais usada para testes em Go.
- [Ginkgo](https://onsi.github.io/ginkgo/) — Framework de testes no estilo BDD (comportamento), com relatórios detalhados.
- [mockery](https://vektra.github.io/mockery/) — Gera mocks automaticamente a partir de interfaces Go para uso em testes.
- [Zap](https://github.com/uber-go/zap) — Biblioteca de logging estruturado de altíssima performance, mantida pela Uber.
- [zerolog](https://github.com/rs/zerolog) — Logger estruturado com zero alocações, focado em performance.
- [k6](https://k6.io/) — Ferramenta de teste de carga escrita em Go, com scripts de teste em JavaScript.

## 🤖 IA na prática

Go tem uma relação direta com o mundo de IA: a própria pesquisa oficial do time do Go mostra que **70% dos desenvolvedores já usam assistentes de IA** no dia a dia ([Go Developer Survey 2024 H2](https://go.dev/blog/survey2024-h2-results)), e boa parte da infraestrutura que roda modelos de IA em produção (Kubernetes, Docker, ferramentas de observabilidade) é escrita em Go.

**Para aprender**
- Cole um erro de compilação (ex.: `cannot use x (variable of type int) as string value`) e peça para a IA explicar a causa e mostrar a forma idiomática de corrigir, sem apenas silenciar o erro com `interface{}`.
- Peça para a IA comentar, linha a linha, um trecho com goroutines e channels — é onde mais vale a pena entender antes de aceitar.
- Peça exercícios com gabarito sobre o tópico que está estudando (slices vs arrays, ponteiros, interfaces, generics) e depois rode no [Go Playground](https://go.dev/play/) para confirmar o comportamento.
- Peça para converter uma função síncrona em concorrente usando goroutines e um `sync.WaitGroup`, e explique por que aquela sincronização é necessária.

**Para trabalhar**
- [GitHub Copilot](https://github.com/features/copilot), [Cursor](https://cursor.com/) e [Claude Code](https://code.claude.com/docs/en/overview) têm bom suporte a Go via [`gopls`](https://pkg.go.dev/golang.org/x/tools/gopls), o language server oficial da linguagem — é ele quem dá o contexto de tipos para o autocomplete e o chat.
- Depois de cada sugestão aceita, rode `go vet`, `go test ./...` e o [`golangci-lint`](https://golangci-lint.run/). Go tem tipagem estática e compilador rigoroso — use isso como um segundo revisor automático do que a IA escreveu.
- Para construir aplicações de IA em Go: o [SDK oficial do Google para Gemini](https://ai.google.dev/gemini-api/docs/libraries), o [SDK oficial da Anthropic em Go](https://github.com/anthropics/anthropic-sdk-go), o [SDK oficial do Model Context Protocol em Go](https://github.com/modelcontextprotocol/go-sdk) (para criar servidores MCP) e o cliente [go-openai](https://github.com/sashabaranov/go-openai) (não oficial, mantido pela comunidade) cobrem os principais provedores.

**Limites e boas práticas**
- IA erra em detalhes de concorrência: pode sugerir código com data race que só aparece sob carga. Rode sempre com `go test -race` antes de confiar em código concorrente gerado por IA.
- Ela às vezes sugere pacotes ou funções que não existem na versão do Go do seu projeto (alucinação), principalmente para recursos recentes como generics ou `encoding/json/v2`. Confirme na [documentação oficial](#-documentação-oficial).
- Nunca cole chaves de API, credenciais de banco de dados ou dados de produção em ferramentas de IA sem a política de segurança da sua empresa.
- Entenda o que você aceita: em entrevista técnica e em produção, o código é seu, não da IA.
